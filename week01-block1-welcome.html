Why does a biologist need code?

By hand

  • 1 FASTA file → OK
  • 500 FASTA files → a week of copy & paste
  • “Which version of the table did I use?” 🤯

With code

  • 500 files → one script, a few seconds
  • Same result every time
  • Full history of every change

Keep it short. The goal is motivation, not a lecture.

Less listening, more coding.

Rules of our online room

  • 🎥 Camera on during pair work, if you can
  • 👥 Pairs: one shares the screen, the other guides — switch every 10 min
  • ✅ Reaction = “it works” · ✋ Raise hand = “I need help”
  • ⏱️ Stuck for more than 5 minutes? Write in the chat
  • ❌ Errors are normal — reading them is a skill we will learn
  • 💾 Every class ends with a commit

Stress the 5-minute rule: online, beginners get stuck silently.

Oral exam 💬

  • 15 minutes per person, in the last week of classes
  • We talk about your final project code
  • Goal: see what you have learned

This is a conversation, not an interrogation. 🙂

No attendance tracking — but practice in class is where you learn.

Oral exam questions ideas: walk me through your script; why did you use a dictionary here; what would you change; what was the hardest part. Timing: week 14 has 160 min → only ~10 students in class time. Plan extra slots if the group is bigger.

AI tools (ChatGPT, Copilot, Claude…)

✅ OK

  • Explaining an error message
  • Explaining what a piece of code does

❌ Not OK

  • Generating complete solutions to assignments
  • Submitting code you cannot explain

Rule of thumb: if you can’t explain it, don’t submit it.
