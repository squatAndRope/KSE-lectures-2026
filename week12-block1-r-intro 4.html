Vectors: R’s superpower ⚡

lengths <- c(120, 85, 300, 42)

length(lengths)     # 4
mean(lengths)       # 136.75
max(lengths)
sort(lengths)

lengths * 2         # every element doubled — no loop! 🤯
lengths > 100       # TRUE FALSE TRUE FALSE

In R, operations work on whole vectors at once.

The no-loop vectorisation is the genuine “wow” moment. Compare with the Python loop they wrote in week 5.

Indexing ⚠️

lengths[1]              # the FIRST element — R counts from 1! 🤨
lengths[c(1, 3)]        # first and third
lengths[lengths > 100]  # filtering by condition 🎯

Warning

Python counts from 0, R counts from 1. This will bite you. 🐛

Data frames: tables 📊

seqs <- data.frame(
  name   = c("seq1", "seq2", "seq3"),
  length = c(120, 85, 300),
  gc     = c(0.55, 0.41, 0.62)
)

head(seqs)          # first rows
nrow(seqs)          # number of rows
seqs$length         # one column as a vector
mean(seqs$gc)

A data frame is a spreadsheet you can compute with 🧮

Filtering rows 🎯

seqs[seqs$length > 100, ]          # rows where length > 100
seqs[seqs$gc > 0.5, "name"]        # just the names
seqs$gc_percent <- seqs$gc * 100   # add a new column ➕

The comma matters: [rows, columns] 📐
